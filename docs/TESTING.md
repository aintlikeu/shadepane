# Ручная проверка интерфейса на Windows

Логика (адрес/поиск, настройки, история, закладки, горячие клавиши, шаги масштаба) покрыта тестами в
`tests/`. Интерфейс WPF и поведение WebView2 тестами не покрыты — их нужно проверить руками по этому
списку перед релизом. Защита от захвата экрана — отдельно, в [`SPIKE.md`](SPIKE.md) (шаги 1, 4, 6).

```powershell
dotnet run --project src\Shadepane.App
```

## Вкладки

| Проверка | Ожидаемо |
|---|---|
| «+» и Ctrl+T | новая вкладка с домашней страницей, фокус в адресной строке |
| Ctrl+W, ✕ на вкладке, средний клик по вкладке | вкладка закрыта; закрытие последней закрывает окно |
| Ctrl+Tab / Ctrl+Shift+Tab, Ctrl+1…8, Ctrl+9 | переключение вкладок |
| Ссылка с `target=_blank` | новая вкладка рядом с текущей |
| Ctrl+клик по ссылке | новая вкладка в фоне |
| «Войти через …» (окно входа, `window.open`) | открывается во вкладке, после входа исходная страница получает результат |
| `window.close()` на странице | закрывает свою вкладку |
| Снимок экрана (`tools\screen.ps1`) с несколькими вкладками | окна браузера нет на снимке |

## Значки

| Проверка | Ожидаемо |
|---|---|
| Панель: назад, вперёд, обновить, ☆, пазл, загрузки, «⋯», «+» вкладки, ✕ на вкладке, «»», ▲▼ в поиске и в окне закладок | значки, а не символы-эмодзи; одинаковой толщины; чёткие при масштабе 100–200% |
| Неактивные кнопки (назад без истории) | значок серый |

| Доступно обновление | кнопка со значком «стрелка вверх» и текстом «Обновить до X» |

## Внешний вид

| Проверка | Ожидаемо |
|---|---|
| Кнопки панели, закладок и поиска | без рамок; при наведении — серая подложка со скруглением, при нажатии темнее |
| Tab по кнопкам | рамка фокуса синяя скруглённая, а не пунктир |
| Вкладки | активная — цвета панели под ней, без рамки; неактивные прозрачные, текст серый, при наведении подсветка |
| Адресная строка без фокуса | скруглённая; домен тёмный, путь серый; `https://` скрыт, `http://` виден; пустая вкладка — «Введите адрес или поисковый запрос» |
| Клик в адресную строку | белый фон, синяя рамка, весь адрес целиком и выделен |
| Ввести текст и кликнуть на страницу | ввод отброшен, снова адрес страницы; Alt+Tab во время ввода — ввод сохраняется |
| `https://bank.example@evil.test` (если откроется) | домен не выделяется |
| Звезда внутри строки | синяя закрашенная, если страница в закладках |
| Загрузка страницы | под панелью бежит синяя полоска; «Обновить» превращается в крестик «Остановить»; при выключенных анимациях Windows полоска стоит на месте |
| Ctrl+D, Ctrl+=, скачать файл | голубая строка-уведомление под панелями, исчезает сама через ~5 с |
| `javascript:alert(1)` в адресной строке, переход на `file:///` по ссылке | жёлтая строка-уведомление; висит до «Закрыть», следующего перехода или смены вкладки |
| Строки состояния внизу окна | нет; адрес ссылки при наведении показывает сам WebView2 внизу страницы |
| Шрифт | Segoe UI Variable на Windows 11, Segoe UI на Windows 10; 13 px, чёткий при 100% |
| Поля ввода в окнах | скруглённые, в фокусе синяя рамка |
| Настройки | заголовки групп полужирные, без рамок вокруг групп |
| Списки истории, закладок, загрузок | строки выше, заголовки колонок плоские; ширину колонок можно менять перетаскиванием |
| Кнопки в окнах настроек, истории, закладок, загрузок | скруглённые с тонкой рамкой; «Сохранить» в настройках — синяя |

## Настройки (⚙)

| Проверка | Ожидаемо |
|---|---|
| Домашняя страница: поисковик / пустая / свой адрес | Alt+Home и новые вкладки открывают выбранное |
| Свой адрес `javascript:alert(1)` | «Сохранить» показывает ошибку, окно не закрывается |
| Поисковик Startpage, затем свой шаблон `https://search.example/?q={query}` | поиск из адресной строки идёт туда |
| Свой шаблон без `{query}` или `http://` | ошибка при сохранении |
| «Отмена» и крестик | ничего не сохраняется |
| Политика с `homeUrl` / `searchUrl` / `allowDownloads` / `allowExtensionClipboardRead` | поле неактивно, «Задано администратором» |

## Установщик

| Проверка | Ожидаемо |
|---|---|
| `Shadepane-<версия>-win-x64-setup.exe` без прав администратора | установка в `%LOCALAPPDATA%\Programs\Shadepane`, ярлык в «Пуске», флажок «Запустить» в конце |
| «Для всех пользователей» на первой странице (или `/ALLUSERS`) | запрос UAC, установка в Program Files |
| Установка поверх запущенного браузера | установщик закрывает браузер перед заменой файлов |
| Иконка: у установщика, `Shadepane.exe` в Проводнике, ярлыка в «Пуске», в заголовке окна, на панели задач и в Alt+Tab | везде щит с перечёркнутым глазом, без размытия при масштабе 100–200% |
| Удаление через «Параметры → Приложения» | программа удалена; `%LOCALAPPDATA%\Shadepane` (закладки, история) остаётся |
| Машина без WebView2 Runtime | после установки — предложение открыть страницу загрузки |

## Автообновление (нужны два релиза: установить старый, опубликовать новый)

| Проверка | Ожидаемо |
|---|---|
| Запуск установленной старой версии | через ~10 с кнопка «⬆ Обновить до X» |
| Кнопка → «Да» | ход загрузки в уведомлении под панелями, браузер закрывается, ставится и запускается новая версия; в журнале `update-installing` |
| ⚙ → «Проверить сейчас» на последней версии | «Обновлений нет» |
| Портативная версия (zip) | кнопка открывает страницу релиза |
| Подменить установщик в `%TEMP%\Shadepane-Update` во время загрузки | «контрольная сумма не совпала», файл удалён |
