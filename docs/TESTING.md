# Ручная проверка на Windows

Логика (адрес/поиск, настройки, история, закладки, горячие клавиши, шаги масштаба, проверка расширений
и политики) покрыта тестами в `tests/`. Интерфейс WPF, поведение WebView2 и защита окна тестами не покрыты —
их нужно проверить руками по этому списку перед релизом.

```powershell
dotnet run --project src\Shadepane.App
# тестовая страница по http (file:// браузер не открывает намеренно):
python -m http.server 8000 --directory samples\test-pages     # или: npx --yes http-server samples\test-pages -p 8000
```

Тестовая страница: `http://localhost:8000/capture-test.html`. Журнал: `%LOCALAPPDATA%\Shadepane\audit.log`
(в PowerShell — `$env:LOCALAPPDATA\Shadepane\audit.log`). Начать «с чистого листа» — закрыть браузер и удалить
`%LOCALAPPDATA%\Shadepane`.

## Защита от захвата экрана

На открытой `capture-test.html`. Ожидаемо: окна браузера нет на снимке (или на его месте пусто), остальной
рабочий стол виден.

| Способ | Ожидаемо |
|---|---|
| Win+Shift+S, PrintScreen → Paint, Alt+PrintScreen | окна нет |
| OBS: захват экрана и захват окна, ShareX, Win+G (запись) | окна нет |
| Teams / Zoom: демонстрация экрана и окна Shadepane | окна нет |
| Всплывающие элементы страницы (раздел 1): `<select>`, календарь, datalist, title-подсказка, выбор цвета, контекстное меню, `alert()` (раздел 2) | на снимке нет |
| Popup расширения, панель «Сведения о защите», меню «⋯», подсказки | на снимке нет |

Всплывающие элементы снимайте `tools\screen.ps1`: «Ножницы» с таймером забирают фокус, и элемент закрывается
до снимка. `powershell -ExecutionPolicy Bypass -File tools\screen.ps1 -Delay 5`, затем открыть элемент
и ничего не трогать до снимка.

| Проверка | Ожидаемо |
|---|---|
| Debug-сборка: клик в адресную строку, Ctrl+Alt+Shift+D (снимает флаг защиты, как внедрённый код) | за ~200 мс содержимое скрыто, сообщение о нарушении защиты, браузер закрыт; в журнале `capture-guard-tripped` |
| Запуск по RDP | отказ запуска |
| Браузер запущен локально, затем подключение к этой сессии по RDP | срабатывание защиты (`remote-session`), закрытие |

## Каналы утечки (раздел 3 тестовой страницы)

| Действие | Ожидаемо |
|---|---|
| Ctrl+P, кнопка `window.print()` | ничего не происходит |
| F12, Ctrl+Shift+I | DevTools не открываются |
| Правый клик | нет «Печать», «Сохранить как», «Просмотреть код» |
| `getDisplayMedia()` | заблокирован, `screen-capture-blocked` в журнале, индикатор «Захват экрана отклонён» |

| `window.open(data:)` | ничего, `new-window-blocked` в журнале |

| Ctrl+P / Ctrl+S в PDF, правый клик в PDF | ничего не происходит / только разрешённые пункты; в журнале `shortcut-blocked` |
| Правый клик по выделенному тексту / в поле ввода | есть «Копировать» / «Вставить» / «Выделить всё» |

## Расширения и политика

| Проверка | Ожидаемо |
|---|---|
| Пазл → «Добавить расширение…» → `samples\extensions\spike-popup` | зелёная иконка; в popup все пункты зелёные; счётчик «+1» сохраняется после закрытия popup и перезапуска |
| С политикой по умолчанию добавить `samples\extensions\evil-capture` | отказ с причинами (`activeTab`, `tabs`, `<all_urls>`) |
| Debug: `samples\policies\spike-permissive.json` → `bin\Debug\net10.0-windows\policy.json`, запуск `dotnet run --no-build`, добавить `evil-capture`, затем вернуть `default.json` и перезапустить | расширение отозвано: иконки нет, в журнале `extension-revoked` |
| Закрыть браузер, дописать строку в `popup.js` копии `spike-popup` в `%LOCALAPPDATA%\Shadepane\extensions`, запустить | расширение отозвано: «файлы расширения изменены после одобрения» |
| Release, обычный пользователь: `C:\ProgramData\Shadepane\policy.json`, созданный без прав администратора | отказ запуска «политику может изменить не только администратор» |
| Release: `C:\ProgramData\Shadepane` — junction на папку пользователя | отказ запуска «ссылка (symlink/junction)»; удалить ссылку `cmd /c rmdir C:\ProgramData\Shadepane` (не `Remove-Item`) |
| Политика в `HKLM\Software\Policies\Shadepane` (README, раздел «Policy») | запуск; в журнале `app-start` — `policySource` = ключ реестра |
| Мусор в `policy.json` с правильными правами | отказ запуска, а не политика по умолчанию |
| Своё расширение без браузера: `dotnet run tools/check-extension.cs -- <папка> samples\policies\default.json` | принято или причины отказа |
| Chrome Web Store: страница любого расширения → кнопка установки | загрузка не появляется в списке загрузок; окно «Установить расширение «Имя» версия?» с доступом к сайтам и правами; «Да» — значок на панели; в журнале `webstore-package-intercepted`, `webstore-package-downloaded`, `webstore-installed` с `installedId` = ID из адреса страницы |
| То же, «Нет» в окне подтверждения | ничего не установлено, «Установка отменена» |
| Магазин: расширение с правами из `blockedPermissions` (например, со скриншотами страниц) | отказ политикой без окна подтверждения, в журнале `extension-rejected` с `source: webstore` |
| Магазин: пазл → «Установить с этой страницы Chrome Web Store» (пункт есть только на странице расширения) | то же окно подтверждения, что и у кнопки магазина |
| Повторная установка уже стоящего расширения из магазина | окно «Обновить расширение … до версии …»; после — одно расширение, не два |

Очистка после проверок политики (от администратора):
```powershell
Remove-Item -Recurse -Force 'HKLM:\Software\Policies\Shadepane' -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force C:\ProgramData\Shadepane -ErrorAction SilentlyContinue
```

| Поисковик Startpage, затем свой шаблон `https://search.example/?q={query}` | поиск из адресной строки идёт туда |
| Свой шаблон без `{query}` или `http://`, Enter | красная ошибка под полем «Шаблон не сохранён»; поиск остаётся прежним |
| Поисковик не «Свой шаблон…» | поля шаблона и подсказки под списком нет; выбрали «Свой шаблон…» — поле появилось |
| Политика с `homeUrl` / `searchUrl` / `allowDownloads` / `allowExtensionClipboardRead` / `restoreSession` | поле неактивно, «Задано администратором» |

## История (🕘, Ctrl+H)

## Закладки

| Проверка | Ожидаемо |
|---|---|
| ☆ / Ctrl+D на странице | ★, закладка на панели закладок; повторно — убрать |
| Панель: клик / Ctrl+клик / средний клик / правый клик | открыть / в новой вкладке / в новой вкладке / меню |
| «»» | все закладки списком и «Управление закладками» |
| Ctrl+Shift+O: правка названия и адреса, ▲▼, удаление | меняется и на панели; на кнопках ▲▼ видны стрелки вверх и вниз |
| Перетащить закладку на панели закладок влево / вправо / в конец | синяя черта показывает место; закладка встаёт туда, порядок сохраняется после перезапуска и виден в Ctrl+Shift+O |
| Короткий клик по закладке, Ctrl+клик, средний клик | открывает, как раньше; после перетаскивания закладка не открывается |
| Перетащить закладку на страницу или в адресную строку | ничего не происходит |
| Значки на панели закладок | у сайтов, которые открывались после добавления закладки, — их значок; у остальных — первая буква сайта на голубом квадрате |
| Ctrl+D на странице | значок появляется на новой закладке сразу |
| Удалить закладку | её значок удалён из `%LOCALAPPDATA%\Shadepane\favicons` (если у сайта не осталось других закладок) |
| Ctrl+Shift+B и флажок в настройках | панель скрывается / показывается, состояние переживает перезапуск |

## Установщик

| Проверка | Ожидаемо |
|---|---|
| `Shadepane-<версия>-win-x64-setup.exe` без прав администратора | установка в `%LOCALAPPDATA%\Programs\Shadepane`, ярлык в «Пуске», флажок «Запустить» в конце |
| «Для всех пользователей» на первой странице (или `/ALLUSERS`) | запрос UAC, установка в Program Files |
| Установка поверх запущенного браузера | установщик закрывает браузер перед заменой файлов |
| Иконка: у установщика, `Shadepane.exe` в Проводнике, ярлыка в «Пуске», в заголовке окна, на панели задач и в Alt+Tab | везде щит с перечёркнутым глазом, без размытия при масштабе 100–200% |
| Удаление через «Параметры → Приложения» | программа удалена; `%LOCALAPPDATA%\Shadepane` (закладки, история) остаётся |
| Машина без WebView2 Runtime | после установки — предложение открыть страницу загрузки |

## Автообновление (нужны два релиза: установить старый, опубликовать новый)

| Проверка | Ожидаемо |
|---|---|
| Запуск установленной старой версии | через ~10 с кнопка «⬆ Обновить до X» |
| Кнопка → «Да» | ход загрузки в уведомлении под панелями, браузер закрывается, ставится и запускается новая версия; в журнале `update-installing` |
| Настройки → «Проверить обновления» на последней версии | «Обновлений нет» |
| Портативная версия (zip) | кнопка открывает страницу релиза |
| Подменить установщик в `%TEMP%\Shadepane-Update` во время загрузки | «контрольная сумма не совпала», файл удалён |
